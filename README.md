### Models & Methods

- **Clinical time-series** — Temporal Transformers for postoperative stay prediction in [RecoveryLens AI](https://github.com/harinisv29/RecoveryLens_AI), GAN-based imputation with a GRU baseline in [ChronoGAN](https://github.com/harinisv29/chronogan), and LSTM forecasting in [SilentPulse](https://github.com/harinisv29/SilentPulse).
- **Graph machine learning** — Hypergraph neural networks for phenotype-based rare disease ranking in [DiseaseMimic AI](https://github.com/harinisv29/DiseaseMimic_AI).
- **Medical computer vision** — Mask R-CNN instance segmentation in [Brain Tumor](https://github.com/harinisv29/brain_tumor), plus EfficientNet and Grad-CAM in [MalariaDetect AI](https://github.com/harinisv29/MalariaDetect-AI).
- **Clinical documents and NLP** — OCR-based medical report extraction and retrieval-augmented generation (RAG) in [Medical Report Assistant](https://github.com/harinisv29/Medical-Report-Assistant).
- **Tabular ML and explainability** — XGBoost and SHAP for claim risk scoring in [Healthcare Insurance Claim Fraud Detector](https://github.com/harinisv29/AI-Powered-Healthcare-Insurance-Claim-Fraud-Detector).
